ENJOY CREATOR ACADEMY — Brand New Website

A fresh, responsive academy website with a premium violet, mint and white visual identity. The founder section is intentionally excluded.

Files are kept together in this single root folder. Every HTML page includes its own inline CSS and JavaScript; there are no separate CSS or JS files.

Pages: index.html, course.html, portal.html, privacy.html, refund.html, terms.html

Open index.html to preview locally. Upload all files together to the same public web root when deploying. The Learning Portal links open the configured Google Drive learning folder. Course enrollment uses the supplied Razorpay payment link.

Note: This is a static website. Google Drive permissions, payment confirmation, and course enrollment automation are managed by their respective services and are not implemented by this front-end.

Lesson 15 (How to Create AI Movies) is marked UPCOMING and clearly labelled as not available yet. Lessons 01–14 are listed as the currently available course roadmap.
